# Greenways OS AI capability

This project declares `:model/generate` and calls the portable `gw.ai`
namespace. Replace the public profile and model IDs in `src/main.hal`, then
evaluate `(ask)` in the REPL. Provider credentials remain in Greenways OS.

See [`docs/greenways-os-ai.md`](../../docs/greenways-os-ai.md) for setup and
unavailable-capability behaviour.

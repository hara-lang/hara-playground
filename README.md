# Hara Playground

The browser-first Hara Studio, published at `playground.hara-lang.org`.

It runs projects locally in the browser. Documentation and reference material live at [docs.hara-lang.org](https://docs.hara-lang.org/).

## Build

`bash scripts/build-site` downloads the pinned Hara Studio runtime, verifies it, and writes the static Pages artifact to `site/`.
